# Java Completo - Prof. Nélio

Um repositório dedicado aos estudos e projetos do curso **Java Completo** com o Professor Nélio Alves.

## 📚 Sobre este Repositório

Este repositório contém exercícios, projetos e exemplos práticos desenvolvidos durante o curso completo de Java. O objetivo é consolidar os conhecimentos de programação orientada a objetos, estruturas de dados, APIs Java e outras tecnologias relacionadas.

## 🎯 Objetivos

- ✅ Aprender os fundamentos de Java
- ✅ Dominar programação orientada a objetos (POO)
- ✅ Implementar estruturas de dados e algoritmos
- ✅ Trabalhar com APIs e frameworks populares
- ✅ Desenvolver aplicações robustas e escaláveis

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: Java
- **IDE**: IntelliJ IDEA / Eclipse (ou sua preferência)
- **Build Tool**: Maven / Gradle
- **Versionamento**: Git

## 🚀 Como Usar

1. Clone este repositório:
```bash
git clone https://github.com/jocsamendonca/java-completo-prof-nelio.git
```

2. Navegue até o diretório do projeto:
```bash
cd java-completo-prof-nelio
```

3. Abra o projeto em sua IDE favorita e explore os exercícios e projetos.
